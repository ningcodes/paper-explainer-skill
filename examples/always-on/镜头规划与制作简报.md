## 配音与音轨
- 任意 TTS 出 wav（当时用的是某商用 TTS 网页，按段生成 8 批，读错的 3 句单句重生成），`engine/voice/align.py` 对齐成 `full/timeline.json` + `full/clauses.json`。仓库里的 timeline / clauses 就是那次的真实时间（结尾一句改成了通用署名，时间未动）；配音 wav 不分发。
- 音乐和音效：`engine/audio/audiolib.py`，各章 cues 合并；两遍 loudnorm I=-16:TP=-1.8:LRA=11，真峰值 ≤ −1.5 dBTP。

## 渲染：只走一条路
本机 Chrome 页面内逐帧 `render(t)` + WebCodecs 硬件编码（`engine/common/shell-wc.html`）。开渲前先测 10 秒的 ms/帧和 WebGL renderer；退回软件渲染（SwiftShader 等）就停下报告。一个标签只下载一次，渲完关。合成禁用 geq；混音不用 -shortest，音画差 < 1 帧。当时实测 Apple M4：约 5–7 ms/帧。

## 片头审片已知的小问题（全片顺带避免）
- 网页正文约 18px 偏小：钻进原文时推近到正文 ≥28px 再停。
- 滚动峰值速度偏快：原文页滚动用 easeInOutCubic，峰值 ≤ 900 px/s，停稳后再划黄笔。

## 速度取舍（这一期要求一小时内出片）
- 不做逐帧精修；先保证流程完整、可读、无空屏、原文停留 ≥3 秒。每章自检一次。
- 自检用静帧即可（本机 headless 打开 shell 页 seek(t) 截静帧，只看图）；成片只走 WebCodecs。
- 浏览器同一时间只给一个 agent 用。
