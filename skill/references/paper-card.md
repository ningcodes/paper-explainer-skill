# 论文卡模板（精读后、写稿前填完；按顺序写）

每个数字带出处（页码 / 图号 / 表号）和适用范围。论文没说的一律标「推测」。

1. **问题**：想解决什么，为什么重要。
2. **前人怎么做、为什么不够**：点名具体工作（不写「不少工作」）。
3. **作者思路重建**：只用已有背景、失败模式、观察和相关工作，推演作者怎么想到这个 idea；每步标出处，论文没说的标「推测」。
4. **一句话本质**：一句能被复述的话（例：「不看答案，看做法」）+ 一句补充。
5. **层级表**：

   | 谁在干活（模型名 / 代码） | 改什么 | 拿什么打分 / 输出什么 | 实验中变还是固定 |
   |---|---|---|---|

   不许省略模型名和角色；标明模型权重有没有变、有没有强化学习。
6. **论文自带的具体例子**：示例代码 / 样例输入 → case study → 曲线标注 → 表格单行；记页码图号；用它讲「输入 → 处理 → 输出」。优先用论文自己的例子，不要自己编。
7. **机制**：每个关键设计 + 论文给的参数；每个设计写出**操作定义**（谁、看什么、怎么判定）和「为什么这样设计」的依据（消融、论文原话）；消融要写清对照组具体怎么做的。
8. **实验按「问题 → 实验 → 答案」**：每个数字带出处 + 适用范围（benchmark、设置、k、跑几次）。不同预算 / k 的数字放在一起比时，画面上标出 k。
9. **攻击面**：最脆弱的假设、反例怎么设计、输给基线的格子、失败案例、成本、评分方式。
10. **一周最小复现**：一个人一周能复现的最小版本是什么。
11. **作者措辞强度**：确定 / 推测 / may account for，逐条标。
12. **标题概念核对**：标题、钩子、平台热词里的关键词（如「自进化」「递归」）在论文里具体指什么、哪里体现、哪里不成立。
