# 常见坑全集（合并去重；括号里是来源，便于回查当时的情境）

## 内容与口播
- 照摘要顺序讲 → 成绩单。结果要按问题讲。（早期单篇复盘）
- 只有类比没有例子 → 抽象。用论文自己的例子走一遍。
- 只讲方法、不讲作者怎么想到的 → 学不到可迁移的思路。
- 只讲设计、不讲为什么这样设计 → 观众记不住。
- **用名词代替解释**（「论文管这叫行为对比」却没说怎么比）→ 作者追问「没有标准答案怎么判断」。（Harness² 复盘）
- **跳步**（从诊断直接到「提两份改法，分工不同」）→ 观众在 2 分钟处丢失。（Harness² 复盘）
- **标题承诺没兑现**（说了「自进化」却没讲体现在哪）→ 标题党。
- 对照实验只报结果不说对照组怎么做 → 「换成不分工的是啥意思」。
- 核查后只加了准确度、没重测理解 → 变密、变难懂。
- 盲读提过的问题只补一句了事 → 成片后又被问出来。
- 删掉「谁在干活」（模型名和角色）→ 以为「就是个 loop」或「模型在自己改自己」。
- 没说清哪一层在实验里固定 → 质疑「这算什么递归」。
- 术语前后两个叫法 → 观众以为是两样东西。
- 一句里塞多个数字（尤其带同一个数字的）→ 听岔。
- **每句都塞「机构 + 年份 + 方法 + 数字」** → 一口气念完听着累。机构年份放来源卡。（多来源综述 v5）
- **把多来源串讲当成「不是论文视频」而不加载本 skill** → 五版全部返工。（多来源综述 v1–v5）
- 结尾说教 → 距离感。用「我们」「我自己」。
- 把只在一个设置下成立的结论说成普遍；把推测说成原文；把设计意图说成已证实结果；钩子里的「最强」没核实。
- 讲技术时夸大「没有它之前多惨」→ 叙事压力逼出来的推论冒充事实。每句 before 状态也要有出处。
- 自己造比喻（「练习场」「考官」）代替行业原词（RL 环境、verifier）→ 懂行的观众出戏。
- **钩子把最独特的点埋在第二句、第一句先讲术语** → 前 3 秒抓不住人。
- **段段都「段尾抛问题、下一段回答」** → 自问自答太多，AI 味重。一段最多一处。（11 月口播去 AI 味修订）
- 口号式短句（「裁判够硬，就不一样」）→ 听着像广告词，信息量为零。
- 审稿材料一整块文字 → 作者看着累。分段、一句一行，先给逻辑链。
- 问作者技术术语式的二选一 → 看不懂。用大白话说清背景，有默认就直接做。
- 先定风格后改内容 → 返工。

## 画面与镜头
- **每镜淡到空白页再重搭 / 整屏交叉溶解** → 像 PPT。用连续变形、钻进论文、大画布运镜。（Harness² v1；课程作业粗剪）
- **论文原文是一小段字浮在空白页上** → 没有「在读论文」的实体感。用实体纸 + 推进。
- **用视频截帧或灰条占位当论文素材** → 推进后发糊、一眼假。用 PDF 300 / 720dpi 真页面。
- 原文只闪 1 秒 → 失去「在读论文」的感觉。停留 ≥3 秒。
- **同一张表同样方式全屏放大多次** → 重复。第二次起原位放大并换高亮行。
- **钩子前几秒只有角落小字** → 第 0 帧就让主标题占满画面。
- **开头先闪一下大数字再切标题** → 一闪而过。数字留到口播念到时当主角。
- **进度条直接盖在原画面上** → 挡住标题和出处。先留出顶部 64px，分镜时就按安全区排版。
- **进度条上写「钩子」「冷水」** → 出戏。用两字栏目名。
- **各章 agent 自己做进度条 / 字幕 / 头像** → 拼起来几套 UI。固定元素放公用 chrome.js。
- **简报没写死「铺满 70%、中间帧不空」** → 第一轮各章普遍稀，审片 must-fix 全是这个。（按章并行第一轮）
- **甩镜整屏模糊 0.5s 以上 / 落点是空纸** → 一团糊。模糊只在最快几帧、≤0.35s，落点先排好。
- **平移时目的地没内容 / 6 份加权模糊** → 连续几帧近乎空白 + 重影。提前铺骨架，12–16 份等权模糊。
- **浮起的论文截图盖住正在讲的卡** → 停在旁边，用完收进小地图。
- **原图变重画图出残影**：原图位图半透明留着，重画图压在上面 → 两套轮廓。位图 0.1 秒内整块退场；每个框作为独立元素从原图坐标飞到新位置，只在最后 35% 换成我们的样式。（实体纸样片审片）
- **标题叠字**：两行大标题缩小时轨迹交叉。先出后进；换层时旧的层名、栏头在新层号进场前 0.1 秒退完；来源行也是先擦旧行再擦出新行。
- **口播原句做成大字** → 大字只用用词表里的词，≤8 字，不和字幕同时出现完整句。
- **发光 / 渐变光带**：卡 ④ 不弹跳、不发光。强调用麦色底铺开或外框描边。
- **灰字承载信息** → 示意记录行一开始用次要色，讲到时变墨色。
- **只有通用框 + 小字，没有艺术指导** → 动画再好也显得粗。先选风格卡，排好版后逐章美术精修。
- **一支片子里换风格卡 / 借了动法顺带借外观** → 两套 UI。一支一张卡。
- **深色卡里直接放白色 PDF 页** → 像闪光灯。压亮度 + 暗角。
- **原文荧光笔和我们的标注同一个颜色** → 分不清哪句是论文原话。
- **样片里的示意数据带进正片** → 正片所有数字和表格都要来自论文。
- **高密度段两栏常驻 + 中英双标签 + 看不清的小剪报** → 挤。一屏一个主角、文字限额、只留中文。
- CSS 3D（perspective、rotateX）做立体 → 像旧网页、放大就糊。用 Three.js 打光。
- 含文字的层 `scale()>1` 推近 → 位图放大发糊。改布局尺寸重画。
- 随机噪点 / 条码 / 骨架条填充 → 廉价感。示意图用 3–4 档平滑色阶并标「示意」。
- 深色面板淡入 → 先变成一块灰板。用遮罩擦出。
- **推近时头像变半透明** → 像「虚了」。整个滑出画面。

## 声音
- **全片没有音乐和音效** → 转场没有落点。
- **句句之间都停 0.45s、段间 0.7s 以上** → 停顿占 18%，听着一顿一顿。别靠加速补，压句间停顿，只在问句、反转、关键数字前留整拍。
- **音效按峰值归一后 pop / tick / scratch 太轻** → 手机上听不到。整体比人声低约 19 dB，tick 额外 +6 dB。
- TTS 再加速会吞字 → atempo 不超过 1.05。
- 交付前只看画面质检、不逐段转写核对原声首尾词 → 尾音被吃没发现。淡出 ≤2 帧。
- 自动加的情绪标签可能让专名读歪（scheduler 听成 schedule）→ 逐句识别核对，读错单句重生成。
- 混音用 -shortest → 结尾被截。按 timeline 时长补齐。
- AAC 编码会抬峰值 → loudnorm 天花板设 −1.8 到 −2.0，编码后实测。

## 渲染与工程
- **默认用云端 / 无 GPU 机器渲染** → 软件渲染慢 10–100 倍，多等几小时。只走本机 Chrome GPU + WebCodecs，开渲前测 10 秒。（课程作业一）
- **退回软件渲染还硬渲** → 浪费时间。`probe()` 报 SwiftShader 就停。
- **一个标签下载两次** → 第二次被 Chrome 静默拦截。一个输出一个新标签，渲完关。
- 下载后 mv 走浏览器下载目录的文件 → 下次找不到原件。用 cp。
- **改了代码只重渲一部分分段** → 成片混着旧画面。查分段时间戳，拿不准全渲。
- 改了场景代码没重新导出 cues.json → 音效对不上画面。改完先跑 prep_render.mjs。
- **chrome.js 首句字幕不显示**：`dataset.i` 为 '' 时 `'' != 0` 为 false。比较用 `!== String(i)`。
- **`pkill -f` / `pgrep -f` 匹配到自己的命令行** → 杀掉自己的 shell 或等待循环永不退出。等后台任务看日志完成标记或 PID。
- 渲染 / 审片 subagent 读不到模板，只能照描述重写 → 返工。模板先落到磁盘，brief 里给路径。
- 拿旧版 skill 开工 → 规则对不上。开工先确认 skill 是最新版。
- 插值返回 undefined 让整段崩溃 → 每几帧跑一次 JS 报错扫描。
- `pdftotext -bbox` 在部分 poppler 版本直接崩溃 → 用 PyMuPDF 取词框。
- PDF 词里的 ﬁ / ﬂ 连字让短语找不到 → 词框 NFKC 归一化。
- 合成用 geq 逐像素滤镜 → 慢到不可用。禁用。
