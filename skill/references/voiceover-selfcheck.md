# 口播逐句自查清单（交审前逐句过；适用于所有视频线，优先于 SKILL.md 里任何旧写法）

写稿、审稿、盲测、核查类 subagent 的 brief 都要贴这份清单全文。

- 每段结论在前，例子跟上，最后一句收住。不念「结论先说」「第一类」这类套话，用口语带出结论（「先说设计，也就是到底该不该拆」）。
- 删填充句：「这期说的」「先把词定下来」「回到开头」「最后再说」，以及在观众面前念目录或讲解顺序的句子。
- 不写口号式短句，比如「位置对上了，值没对上」「裁判够硬，就不一样」。话要说完整，「硬」这类虚词要讲清指什么。
- 自问自答一段最多一处，只留真问题。「段尾抛问题、下一段回答」不要每段都用。
- 数字一律用百分数绝对值，例如「从百分之三十五涨到百分之六十三」；不用「几成」，不用「十个剩六个」这类换算。
- 不用写稿时的内部词：「证据」「三格」「对应哪一格」「最稳的发现」「最好的结构」。
- 题面、算式、金额、星数这类细节交给画面，口播只留推理链。
- 不用「不是……而是……」句式。
- 官方 claim、实测、推断分开说；推测必须说「我猜」；不写没发生的亲测。
- 用行业原词（RL 环境、轨迹、verifier），不自造比喻；术语全片一个叫法。
- 一句只放一个信息；不要把多个带同一个数字的量串在一句。
- 不夸大「没有这项技术之前」有多惨：讲 before 状态的每句话也要有出处。
- 没有证据不说「最近很火」；旧内容不标「最新」。
- 结尾：讨论问题 → 署名 + 关注语；不预告下集；不说教。
