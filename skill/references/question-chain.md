# 观众问题链 + 逻辑链模板（写稿前必做，和口播一起交作者审）

## 逻辑链（一页）
每段一行：

| 段 | 观众此刻的问题 | 这段的回答（一句） |
|---|---|---|
| 00 导读 | 这篇凭什么值得看？ | …… |
| 01 背景 | 以前的人怎么做，卡在哪？ | …… |

## 问题链（按段，逐句）
格式：「观众听到这里会问什么 → 下一句怎么答」。

```
s02-3 说完「它会自己挑更好的版本」
  → 观众问：没有标准答案，它凭什么知道哪个更好？
  → s02-4 答：……（操作定义：谁、看什么、怎么判定）
```

## 必须覆盖
- 核心机制「凭什么 / 怎么判断」（例：没有标准答案，怎么知道变好了？）
- 每个角色是谁、权重变不变、有没有强化学习
- 标题和钩子里每个关键词体现在哪
- 每个设计「为什么要这样」
- 每个对照实验「对照组怎么做的」
- 冷水段：至少一个审稿人会问的问题

## 自问自答的用量
自问自答一段最多一处，只留真问题；不要每段结尾都抛问题。问题链是写稿工具，不是要把每个问题都念出来。
