# 独立审片清单（审片 agent 用；没参与制作的 agent 看完整动态片）

输入：成片 mp4、本 skill、论文卡 / 事实口径表、口播稿。输出 `REVIEW-vN.md`：must-fix / should / nice，每条带时间码、违反哪条规则、具体改法；每章一个 1–10 分。第二轮 must-fix 只留观众一眼能看出的问题。

## 怎么看
- 抽帧：每镜中点和末尾、首尾、原文页出现后 1 秒；全片 0.5s 一张做联系表。
- **每个转场按 6fps 展开**（`ffmpeg -ss <t-0.5> -t 1.2 -i film.mp4 -vf fps=6,scale=640:-1,tile=4x2 out.jpg`），不许出现空白页过渡帧。
- 按 1×、2× 放大和手机尺寸各看一遍。
- 响度：`ffmpeg -i film.mp4 -af ebur128=peak=true -f null -` → 整体约 −16 LUFS，真峰值 ≤ −1.5 dBTP。
- 帧数：`ffprobe -v error -count_frames -select_streams v:0 -show_entries stream=nb_read_frames -of csv=p=0 film.mp4` = timeline 帧数；音画差 < 1 帧。

## 画面
- [ ] 第 0 帧就有内容（满屏标题或最反直觉的画面），前 3 秒抓得住人
- [ ] 没有「淡到空白页再重搭」和整屏交叉溶解；每个进场元素都有来处
- [ ] 任何一帧（含变形、换镜中间帧）半屏空着不超过 2 秒；内容铺满约 70%
- [ ] 要读的字 ≥28px（来源行、「示意」可 26px）；承载信息的字是墨色
- [ ] 原文清晰停留 ≥3 秒（不含推拉）；推近后不糊（没超过截图分辨率）
- [ ] 原文上的荧光笔是黄色，我们的标注是卡的强调色，没混用
- [ ] 进度条、字幕、来源行只有一套（chrome.js 画的），和片内元素不碰撞
- [ ] 字幕逐字对稿；没有单独一两个字的一行；跨章时句末 +0.25s 收掉
- [ ] 标题没有新旧叠字；旧画面完全退场后新画面才出；没有残影
- [ ] 中文字形没回退到系统字体（prep_render.mjs 的 fontMissing 为空）
- [ ] 没有随机噪点、条码、骨架条填充；示意图标了「示意」
- [ ] 画面语义不误导（竖排箭头不被读成数据流）；图表按比例、轴有标签
- [ ] 数字和事实口径表一致；画面只用口播里出现过的叫法
- [ ] 风格卡标志动作用上了；没有「默认灰框 + 小字」的 PPT 卡片；全片一张卡
- [ ] （有头像时）推近论文时头像整个滑出，不半透明，不挡内容

## 声音
- [ ] 音乐压在人声下，口播最密的段落人声清楚
- [ ] 音效不抢戏，转场都有落点；没有画面运动的时刻没有 whoosh
- [ ] 逐段转写核对原声首尾词，没有吞字；淡出 ≤2 帧

## 内容（对照口播）
- [ ] 标题和钩子里每个关键词正文都有正面回答
- [ ] 结尾：讨论问题 → 署名配置；不预告下集
